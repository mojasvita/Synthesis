# Поиск потенциальных de novo ORF и repeat-associated ORF в геноме *Drosophila melanogaster*

## 1. Цель проекта

Поиск потенциальных de novo ORF в неаннотированной части генома *Drosophila melanogaster*.

## 3. Мягкое маскирование генома с помощью RepeatMasker

Первоначально геном *D. melanogaster* подвергался мягкому маскированию с помощью RepeatMasker.

Мягкое маскирование переводит повторяющиеся участки в нижний регистр, сохраняя исходную последовательность генома.

Это позволяет отличать повторяющиеся последовательности от немаскированных участков без удаления нуклеотидов.

Использованный инструмент: RepeatMasker.

Пример команды (параметры необходимо сверить с исходным запуском):

```bash
RepeatMasker \
    -species drosophila \
    -xsmall \
    -gff \
    genome.fasta
```

Результат:
- геном с мягким маскированием;
- аннотация повторяющихся участков;
- координаты повторов для последующего анализа.

## 4. Выделение неаннотированной части генома

На следующем этапе из генома выделялись участки, не относящиеся к аннотированным генам.

Для этого использовались координаты генов из аннотации генома.

Цель — ограничить поиск ORF областями, которые не были аннотированы как известные гены.

В качестве основы использовались:
- исходная геномная последовательность;
- аннотация генов;
- координаты генов в формате BED.

Пример подготовки BED:

```bash
# Извлечение координат генов из GFF3
awk -F '\t' '$3 == "gene" {
    print $1 "\t" $4-1 "\t" $5
}' annotation.gff3 > annotated_genes.bed
```

Неаннотированные участки определялись как области генома за пределами аннотированных генов.

## 5. Поиск ORF

Поиск ORF осуществлялся по принципу **start-to-stop**.

В анализ включались открытые рамки считывания, начинающиеся со стартового кодона и заканчивающиеся стоп-кодоном.

В результате поиска формировались два основных файла:

1. Нуклеотидные последовательности ORF.
2. Аминокислотные последовательности ORF.

Условная структура результатов:

```text
ORF_search/
├── ORF_nucleotide.fasta
└── ORF_protein.fasta
```

Нуклеотидные последовательности использовались для последующих проверок и BLASTN, белковые — для BLASTP.

## 6. BLASTP против протеомов 28 видов

Аминокислотные последовательности ORF сравнивались с протеомами 28 видов.

Состав базы:
- 18 видов рода *Drosophila*;
- 10 дополнительных видов.

Цель этапа — определить, имеют ли найденные ORF сходство с уже известными белками других организмов.

Для сравнения использовался BLASTP.

Пример команды:

```bash
makeblastdb \
    -in combined_proteomes.fasta \
    -dbtype prot \
    -out proteomes_db

blastp \
    -query ORF_protein.fasta \
    -db proteomes_db \
    -out blastp_28_species.tsv \
    -outfmt 6 \
    -num_threads 8
```

## 7. Первичная фильтрация кандидатов

После BLASTP проводилась фильтрация ORF.

Оставлялись последовательности, удовлетворяющие двум условиям:

1. Отсутствие обнаруживаемых BLASTP-хитов против базы 28 видов.
2. Длина последовательности более 100 аминокислот.

Таким образом исключались:
- ORF с обнаруживаемыми белковыми гомологами;
- короткие ORF длиной 100 аминокислот и менее.

Полученная выборка рассматривалась как набор потенциальных кандидатов для дальнейшего анализа.

Важно: отсутствие BLASTP-хитов не доказывает de novo происхождение последовательности, а лишь означает отсутствие обнаруженного сходства в использованной базе при заданных параметрах поиска.

## 8. Проверка корректности ORF

После фильтрации проводилась дополнительная проверка последовательностей.

### 8.1. Проверка стартового и стоп-кодонов

Для каждой ORF проверялось:
- наличие стартового кодона;
- наличие стоп-кодона;
- соответствие последовательности принципу start-to-stop.

### 8.2. Проверка соответствия нуклеотидной и аминокислотной последовательностей

Нуклеотидные последовательности транслировались в аминокислотные.

Полученные белковые последовательности сравнивались с первоначальными последовательностями из ORF protein FASTA.

Цель — убедиться, что:
- нуклеотидная и белковая последовательности относятся к одной ORF;
- трансляция выполнена корректно;
- отсутствуют несоответствия между двумя файлами.

## 9. Отбор ORF вблизи аннотированных генов

Следующий этап включал отбор ORF, расположенных на расстоянии менее 5 килобаз от аннотированных генов.

Это позволяло сосредоточить дальнейший анализ на ORF, находящихся в геномном окружении известных генов.

Для определения расстояния использовались геномные координаты ORF и аннотированных генов.

Условие отбора:

```text
Distance(ORF, annotated_gene) < 5000 bp
```

## 10. BLASTN против 18 видов Drosophila

Для отобранных ORF проводился BLASTN против последовательностей 18 видов *Drosophila*.

В отличие от BLASTP, здесь сравнивались непосредственно нуклеотидные последовательности.

Цель — определить эволюционную распространённость найденных ORF и выявить последовательности, потенциально специфичные для *D. melanogaster*.

Пример команды:

```bash
makeblastdb \
    -in drosophila_genomes.fasta \
    -dbtype nucl \
    -out drosophila_genomes_db

blastn \
    -query ORF_nucleotide.fasta \
    -db drosophila_genomes_db \
    -out blastn_18_drosophila.tsv \
    -outfmt 6 \
    -num_threads 8
```

## 11. Классификация ORF по BLASTN

После BLASTN проводилась классификация ORF по наличию хитов у разных видов.

Выделялись две основные группы.

### 11.1. ORF с хитами у D. melanogaster и двух ближайших видов

Отбирались ORF, для которых обнаруживались хиты:
- у *D. melanogaster*;
- у двух ближайших к ней видов в используемой выборке.

При этом хиты у остальных исследуемых видов не должны были обнаруживаться.

Такая группа представляет интерес для изучения относительно недавнего эволюционного происхождения последовательностей.

### 11.2. ORF с хитами только у D. melanogaster

Отдельно отбирались ORF, для которых BLASTN выявлял совпадения только в геноме *D. melanogaster*.

Такие последовательности рассматривались как кандидаты с наиболее ограниченным обнаруженным эволюционным распространением.

Важно: видоспецифичность в данном случае определяется относительно исследованной выборки из 18 видов и использованных параметров BLASTN.

## 12. Проверка связи ORF с повторяющимися последовательностями

После поиска и классификации ORF проводилось сопоставление координат ORF с геномом, обработанным RepeatMasker.

Использовалось мягкое маскирование, позволяющее определить, какие части ORF пересекаются с повторяющимися последовательностями.

По результатам ORF разделялись на две группы.

### 12.1. Repeat-unrelated ORF

ORF, не связанные с маскированными повторяющимися областями.

Для этой группы дальнейший анализ завершался после классификации результатов BLASTN.

Полученные последовательности рассматривались как кандидаты потенциальных de novo ORF.

### 12.2. Repeat-associated ORF

ORF, имеющие пересечения с повторяющимися последовательностями.

Для них проводился дополнительный анализ, направленный на определение возможной связи с транспозонами.

## 13. Анализ транспозонов в repeat-associated ORF

Для ORF, связанных с повторяющимися последовательностями, проводилась дополнительная проверка на наличие транспозонных последовательностей.

Цель — установить, являются ли найденные ORF частью известных транспозонов или содержат ли они участки, происходящие от транспозонных элементов.

Проверялись:
- наличие совпадений с транспозонными последовательностями;
- координаты совпадений внутри ORF;
- доля ORF, покрываемая транспозонными последовательностями;
- полнота совпадения последовательностей.

Отдельно рассматривались случаи, когда транспозонное совпадение покрывало 100% последовательности ORF, и случаи, когда покрытие было неполным.

Таким образом, repeat-associated ORF дополнительно разделялись по характеру связи с транспозонными последовательностями.

## 14. Итоговая структура анализа

В результате проекта сформировались два основных направления.

**Направление 1 — потенциальные de novo ORF**

1. Поиск ORF в неаннотированной части генома.
2. BLASTP против 28 протеомов.
3. Отбор ORF без BLASTP-хитов и длиной более 100 aa.
4. Проверка стартовых и стоп-кодонов.
5. Проверка соответствия нуклеотидных и белковых последовательностей.
6. Отбор ORF в пределах 5 kb от аннотированных генов.
7. BLASTN против 18 видов *Drosophila*.
8. Выделение кандидатов с хитами только у *D. melanogaster* либо у неё и двух ближайших видов.
9. Исключение ORF, связанных с повторяющимися последовательностями.

**Направление 2 — repeat-associated ORF**

1. Выделение ORF, пересекающихся с RepeatMasker-маской.
2. Определение связи с повторяющимися последовательностями.
3. Поиск транспозонных последовательностей внутри ORF.
4. Определение доли покрытия ORF транспозонными последовательностями.
5. Выделение случаев со 100% совпадением и неполным совпадением.

## 15. Ограничения интерпретации

Отсутствие BLASTP- и BLASTN-хитов не является самостоятельным доказательством de novo происхождения ORF.

На результаты могут влиять:
- качество сборок геномов;
- полнота аннотаций;
- представленность видов в базах данных;
- параметры поиска BLAST;
- скорость эволюции последовательностей;
- сложность повторяющихся областей генома.

Поэтому полученные последовательности следует рассматривать как потенциальные кандидаты, требующие дальнейшей проверки.
